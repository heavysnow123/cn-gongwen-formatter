字体说明（fonts/）
==================

本工具**只检查**系统是否已安装所需公文字体，**不安装、不改系统**。

检查项（公文规范 GB/T 9704-2012 常用字体）：
  - 仿宋_GB2312（正文，必备）
  - 楷体_GB2312（二级标题 / 签发人，必备）
  - 思源宋体（大标题，开源 SIL OFL，可选）

使用方式
--------
- 在软件「字体」页点击“检查字体状态”，可查看本机字体安装情况。
- 缺失的必备字体会被醒目提示；请自行将字体安装到系统后再排版
  （Windows：双击字体文件 → 安装，或将字体复制到 C:\Windows\Fonts）。

字体授权提示
------------
- 仿宋_GB2312 / 楷体_GB2312 为微软随 Windows（中文版）分发的专有字体，受版权保护。
  本软件不内置、不提供下载、不代为安装，请使用您已合法获得的字体。
- 思源宋体（Source Han Serif / Noto Serif CJK）为 SIL OFL 开源授权，可合法免费获取安装。

注：本目录当前仅存放说明文件；工具不再依赖或打包任何字体文件。
